# Contributing to E-ZPass Rhode Island Project

## Contribution Guidelines

We welcome contributions from the community! Whether you're fixing bugs, adding new features, or improving documentation, you're helping us improve.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Follow the project's coding standards.
4. Commit your changes and push to your fork.
5. Open a pull request to the main branch.

## Reporting Issues

If you encounter bugs or want to request features:
- Search existing issues first.
- Create a new issue if it hasn’t been reported.

## Suggesting Features

Clearly explain:
- The use case.
- Why it benefits users.
- Any proposed implementation (optional).

## Code of Conduct

All contributors are expected to follow respectful, inclusive, and professional behavior.

## Review Process

Pull requests will be reviewed by maintainers. Ensure:
- Code is clean and documented.
- All tests pass.
- Commit messages are descriptive.
